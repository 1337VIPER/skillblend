Where is Blender?

SkillBlend runs Blender in the background to read your files. It never saves them.

Point it at your project

Add the folder your models live in. Add more folders if your project uses a kit or insert library stored somewhere else. SkillBlend finds every .blend, skips backups, autosaves and old revisions (folders starting with _), and works out which techniques each file shows.

Or drop .blend files here

Files it learned from

Each file is matched to the techniques it shows. Click a technique chip to force it on or off for that file (dashed = your override). Untick a file to leave it out completely.

Your style

One card per technique. Measured cards come from your files; generic cards had no file showing that technique and fall back to SkillBlend's built-in workflow. Optional details let you add what a file can't show. Nothing is required.

Build the skill

Writes a Claude Code skill with your style card, a style.py that applies it in Blender, a style_check.py that checks any model against it, and the full method for every technique.
